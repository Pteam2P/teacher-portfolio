# เว็บไซต์ Portfolio นายพัฒน์ปพงษ์ บุญประภาศรี

## วิธีเปิดดู
ดับเบิลคลิกไฟล์ `index.html`

## วิธีใส่รูปประจำตัว
นำรูปไปวางในโฟลเดอร์ `images` และตั้งชื่อว่า:

`profile.jpg`

## วิธีใส่ Portfolio PDF
นำไฟล์ PDF ไปวางในโฟลเดอร์ `documents` และตั้งชื่อว่า:

`portfolio.pdf`

## การแก้ข้อความ
เปิดไฟล์ `index.html` ด้วยโปรแกรมแก้ไขข้อความ เช่น VS Code หรือ Notepad

## ไฟล์หลัก
- `index.html` โครงสร้างและเนื้อหาเว็บไซต์
- `style.css` สี รูปแบบ และการแสดงผลบนมือถือ
- `script.js` เมนูมือถือและเอฟเฟกต์เลื่อนหน้า

## นำขึ้นออนไลน์ฟรี
สามารถอัปโหลดทั้งโฟลเดอร์ไปยัง GitHub Pages, Netlify หรือ Vercel
